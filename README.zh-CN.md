# GPU LimitSeeker

**短测通过，不等于稳定。**

从当前显卡设置出发，由确定性策略细化失败边界，再让AI评估下一步；优先长测更高候选，而不是提前退到一个舒服参数。[完整配置与架构](README.md)

## 先说边界

这是Alpha版。新的通用激进寻限策略和功耗矩阵仅做离线验证，**没有完成新一轮实机认证**。超频可能导致驱动/系统崩溃、数据损坏及硬件损伤；任何压测都不能保证所有游戏稳定或电源瞬态安全。第一次请有人值守，不要把未验证的参数直接挂通宵。

- 实机仅支持满足接口和遥测要求的Windows、单张NVIDIA显卡；不支持的硬件明确拒绝，不伪造成功。
- 首轮使用当前参数，不从零开始。匹配的独立平顶初始曲线需先完成基准，再做原始向量不变写回验证；后续按完整原始向量恢复，不假设“重新拉平”等于精确还原。不支持任意非平顶形状、负初始偏移；原生桥同样尚无新版实机认证。
- 核心、显存、V/F各阶段先短测、细化边界，再从最高短测通过档开始长测；长测失败，降一个分辨率档重筛、重测。
- 功耗档独立验证。100%稳定不能直接套到110%或125%；AI不能放宽温度、功耗、时间或故障预算。
- 不加电压提升，不刷BIOS，不改TDR注册表，不绕过UAC/杀毒，不自动重启。
- 结束默认恢复初始设置；发现用户启动了其他时钟控制器则交还控制，不覆盖用户操作。**不会自动写入小飞机启动档位。**

## 先跑不碰显卡的演示

Python 3.11及以上：

```powershell
python -m pip install .
gpu-limitseeker demo --powers 100,110,125
```

输出明确标为合成数据。时钟、功耗、分数、加速时长全部是假设场景；评估器是脚本夹具，不是真AI。该命令不读取显卡、不启动压测、不下载工具、不访问模型。

## 实机流程

1. 备份小飞机档位、保存工作，确认供电、散热、连接线。首次有人值守。
2. `gpu-limitseeker tools fetch --accept-downloads`：显式下载固定版本GAO和memtest_vulkan，校验哈希，只下载不执行。也可自行提供匹配文件。
3. `gpu-limitseeker init-config config.json`，配置真实模型和凭据环境变量；密钥不要写进文件。配置初始功耗，使用自定义曲线时填写匹配的`baseline_profile`。
4. 如需关闭小飞机/RTSS并交接控制，显式设置`hardware.allow_afterburner_handoff=true`；交接在初始基准通过之后发生。
5. 自行打开管理员终端，再运行：

```powershell
gpu-limitseeker run --config config.json --i-accept-gpu-risk
```

真实AI预检必须在创建硬件后端前通过。模型缺失、拒绝、响应过期或格式错误都停止，不降级成假AI。可用OpenAI兼容接口，或具有所需隔离参数的原生OMP命令行；OMP使用自己的凭据，不接管当前聊天。

## 功耗不是电压

125%是默认板卡功耗的1.25倍，**不是125瓦，也不是最高电压**。提高上限不保证实际性能提高；工具比较实际达到的频率、吞吐、采样功耗和能效。

默认只测100%。若明确批准高功耗，必须同时设置：

- `search.power_limits`：例如`[100,110,125]`；
- `safety.max_power_percent`：批准的百分比上限；
- `safety.max_board_power_w`：批准的板卡瓦数上限；
- 启动时额外加`--allow-above-default-power`。

还必须在实际驱动范围内，且驱动支持`nvidia-smi`功耗写入；报告范围不代表写入一定受支持。电源标称瓦数不能自动证明整机瞬态安全。没有覆盖的功耗档会标未测，不声称已经找完所有极限。

GAO重置会在空载阶段暂时回到100%上限。如果你的明确授权连100%或默认板卡瓦数都不允许，工具会在交接/重置之前拒绝写入，不偷偷越界。

## 时间与恢复

默认每个候选的长测是**满载60分钟＋半载10分钟＋显存60分钟**，还没算开销。核心、显存、三个曲线锚点、最终组合这条常见路径，单功耗就有六轮长测，约13小时；三档功耗可能需要多天。默认总预算24小时；显式配置可到72小时，但全程共享温度、功耗和故障预算，不会每天重置。可明确选择48小时、减少锚点或自行设定更短的验证时长；时长更短，证据强度也不同。超预算不自动缩短测试，未覆盖档位明确标未测。

`--background`创建独立Windows控制进程和控制台，不建计划任务、不做开机循环。运行时持有有界的系统防休眠租约，允许显示器熄屏；不会改系统电源计划，也无法阻止用户主动休眠或系统崩溃。

```powershell
gpu-limitseeker status --run-dir 运行目录
gpu-limitseeker stop --run-dir 运行目录
gpu-limitseeker resume --run-dir 运行目录 --i-accept-gpu-risk
```

本地运行目录默认在`%LOCALAPPDATA%/GPU-LimitSeeker`，不要上传日志、UUID、配置或同意记录。恢复前要明确清除STOP、恢复原始设置；恢复保留累计预算并重做原始基准。已完成、等待AI的结果不重复压测；**中断在压测或原生恢复中，证据不明的轮次绝不自动重放。**

AI只收到白名单化的有限实验指标，不上传UUID、路径、密钥、原始日志。选择的模型服务仍会收到这些指标，并可能计费。
